The full balance sheet lists every account that has a balance, grouped as current assets, fixed assets, current and long-term liabilities, and equity, as at one date. Anything in a group of its own is shown as "other".

## How it works

<PlatformTabs>
<PlatformTab>
<Steps>
<Step>Go to <MenuPath items={["Accounting", "Balance Sheet"]} />.</Step>
<Step>Pick an **As of Date**. It starts as today.</Step>
</Steps>
</PlatformTab>
<PlatformTab>
<Steps>
<Step>Go to <MenuPath items={["Manage", "Accounting", "Financial statements"]} /> and choose **Balance sheet**.</Step>
<Step>Choose **As at**: today, the end of last month, last quarter or last year, or **Choose a date** for any day.</Step>
<Step>Tap the share icon for text, or the PDF icon (if you may export) for a PDF.</Step>
</Steps>
</PlatformTab>
</PlatformTabs>

Worked example, with one posted ₦50,000 dues entry:

| Section | Account | Amount |
|---|---|---|
| Assets | Member Dues Receivable | ₦50,000 |
| **Total assets** | | **₦50,000** |
| Liabilities | none | ₦0 |
| Equity | Earnings so far | ₦50,000 |
| **Total equity** | | **₦50,000** |

**Earnings so far** is worked out, not posted: it is all the income less all the spending up to that date.

## What it counts

- **Every account is shown,** including liabilities that are neither current nor long term, so the sheet adds up whenever the books do.
- **A switched-off account still appears** while it holds money.
- **It says when it does not balance.** If assets differ from liabilities plus equity, the sheet shows a warning. That points to an entry that should not be there, so look at the entries around the date it changed.

Select an account or a total to see everything posted up to the date shown. See [Opening a figure to see the entries behind it](/docs/accounting-guide/opening-a-figure).
