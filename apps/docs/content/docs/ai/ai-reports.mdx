AI reports turn your financial data into a written summary — useful for a board update or handover, not a replacement for the Reports section's own numbers.

## Before you start

You need the **view reports** permission, which Administrators, Treasurers and Financial Secretaries have by default.

## Generate a report

<Steps>
<Step>Go to <MenuPath items={["AI Assistant", "AI Reports"]} />.</Step>
<Step>Choose a report type: **Monthly Summary**, **Quarterly Review**, **Annual Report** or **Treasurer Handover**.</Step>
<Step>Select <UiLabel>Generate Report</UiLabel>.</Step>
</Steps>

<Screenshot src="/images/ai/ai-reports-1.webp" alt="Generate AI Reports page with a report type selector and a Generate Report button" />

<Callout type="note" title="Treasurer Handover is worth knowing about">
This report type is built specifically for an outgoing treasurer to summarise the association's financial position for whoever takes over — useful at an officer transition, not just a routine report.
</Callout>

## What happens next

Each generated report counts against your daily AI usage limit — see [AI usage limits and data privacy](/docs/ai/limits-and-privacy). For the association's actual figures without AI commentary, see [Reports & exports](/docs/reports).
