Smart Reminders suggests which overdue members are worth following up with — it doesn't send anything itself.

## Before you start

You need the **view finances** permission, which Administrators, Treasurers and Financial Secretaries have by default.

## Get reminder suggestions

<Steps>
<Step>Go to <MenuPath items={["AI Assistant", "Smart Reminders"]} />.</Step>
<Step>Select <UiLabel>Refresh Suggestions</UiLabel>.</Step>
<Step>Review the suggested members, each with the AI's reasoning for flagging them.</Step>
</Steps>

<Screenshot src="/images/ai/smart-reminders-1.webp" alt="Smart Reminders page with Refresh Suggestions button and a list of suggested members" />

## What happens next

This page only surfaces who to contact — actually sending a reminder is still the manual, separate action covered in [Following up overdue members](/docs/finance/overdue-and-reminders).
