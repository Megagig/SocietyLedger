Payment settings record which channels you'd like to offer and your default method — cosmetic preferences only, not a switch that turns real payment methods on or off.

## Before you start

You need the **edit settings** permission, which only Administrators have by default.

## Update payment settings

<Steps>
<Step>Go to <MenuPath items={["Settings", "Payment Settings"]} />.</Step>
<Step>Toggle which **Enabled Channels** you want to list (Bank Transfer, Cash, Online), choose a **Default Payment Method**, and toggle **Enable Manual Payments**, **Manual Payment Approval Required**, **Enable Partial Payments** and **Auto-Generate Receipts**.</Step>
<Step>Select <UiLabel>Save Changes</UiLabel>.</Step>
</Steps>

<Screenshot src="/images/settings/payment-settings-1.webp" alt="Payment Settings page with enabled channel toggles, default payment method, and receipt and approval toggles" />

<Callout type="warning" title="Nothing currently reads these values">
These toggles save correctly but nothing elsewhere checks them — Paystack availability is controlled by whether a gateway key is configured (see [Integrations](/docs/settings/integrations)), not by this page's "Enabled Channels" list, and manual payment recording works the same way regardless of what's toggled here.
</Callout>

## What happens next

Nothing changes elsewhere in the app yet — see the callout above.
