An association is your community's own workspace on SocietyLedger — a cooperative, alumni group, staff association, or any similar group.

## How it works

Every association gets its own web address, built from a subdomain you choose when it's created — for example `yourassociation.societyledger.com.ng`. That address is also how you sign in: SocietyLedger works out which association you belong to from the address itself, not from a separate code you type in.

Each association has:
- A **name** and an optional **logo** and **primary color**, shown throughout its dashboard.
- A **plan** (its tier) that decides which [modules](/docs/core-concepts/plans-and-modules) are available and how many members it can have.
- Its own members, transactions, meetings and everything else — completely separate from every other association on SocietyLedger.

## Why it matters

Nothing is ever shared between associations. A member, transaction or document that belongs to one association is never visible from another — even though they're all running on the same SocietyLedger platform. Signing in on one association's address only ever shows you that association.
