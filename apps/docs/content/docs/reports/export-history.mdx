Every export you've generated is kept here for re-downloading — but not forever.

## Before you start

You need the **view export history** permission, which Administrators, Treasurers and Financial Secretaries have by default.

## Check your export history

<Steps>
<Step>Go to <MenuPath items={["Exports", "History"]} />.</Step>
<Step>Find the export by filename, type or date, and check its size and status.</Step>
<Step>Download it again if it hasn't expired yet.</Step>
</Steps>

<Screenshot src="/images/reports/export-history-1.webp" alt="Export History page listing a completed Excel export with its filename, type, created date, expiry countdown, size and status" />

In the app, open **Manage**, **Reports**, **Exports**, then the **History** tab. Tap **Share** on a file to send it. A file that has expired is marked **Expired** and cannot be shared.

<Callout type="warning" title="Exports expire after 7 days">
Each export is only kept for 7 days — the **Expires** column counts down. Generate a fresh one from [Exporting to PDF and Excel](/docs/reports/exporting-reports) once it's gone.
</Callout>

## What happens next

Nothing changes here — this page is a record, not an action.
