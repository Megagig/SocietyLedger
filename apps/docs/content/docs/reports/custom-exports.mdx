When the standard exports have more — or less — than you need, build your own with exactly the fields you want.

## Before you start

You need the **export members** permission, which Administrators, Treasurers and Financial Secretaries have by default.

## Build a custom export

<Steps>
<Step>Go to <MenuPath items={["Exports", "Custom"]} />.</Step>
<Step>Select a **Report Type** — Members, Transactions, Payments, Welfare, Donations, Levies, Penalties or Accounting.</Step>
<Step>Tick the fields you want, or use **Select All** / **Deselect All** to start from either end.</Step>
<Step>Generate the export.</Step>
</Steps>

<Screenshot src="/images/reports/custom-exports-1.webp" alt="Custom Export Builder with Report Type options and a field selector showing Member Information fields, 9 of 16 selected" />

## What happens next

Your file downloads as an Excel workbook with only the columns you chose — it also appears in [Export history](/docs/reports/export-history).
