Exports make a file you can keep, print or send: a financial summary, your member list, or one member's statement.

## Before you start

You need the **export financial** permission for the financial files, and **export members** for the member list and statements. Administrators, Treasurers and Financial Secretaries have them by default.

## Export something

<PlatformTabs>
<PlatformTab>
<Steps>
<Step>Go to <MenuPath items={["Exports"]} />.</Step>
<Step>Under **Quick Exports**, select **Financial Summary** (PDF or Excel), **All Members** (Excel), or **Member Statement** (PDF, after choosing a member).</Step>
<Step>Your file downloads automatically.</Step>
</Steps>
</PlatformTab>
<PlatformTab>
<Steps>
<Step>Go to <MenuPath items={["Manage", "Reports", "Exports"]} />.</Step>
<Step>On **Make a file**, choose **Financial summary** (pick a period and PDF or Excel), **Members list** (choose which members), or **Member statement** (choose a member and, if you want, two dates).</Step>
<Step>Tap **Make PDF** or **Make Excel**. When the file is ready, your phone's share sheet opens, so you can send it by WhatsApp or email, or save it to Files.</Step>
</Steps>
</PlatformTab>
</PlatformTabs>

The financial summary uses the same rules as the [Financial summary report](/docs/reports/financial-summary), so the file matches what you see on screen. Dates in it follow Lagos time.

## What happens next

The file is kept for **7 days**. It is listed under the **History** tab in the app, and in your [Export history](/docs/reports/export-history) on the web, where you can share or download it again without making it again. After 7 days the file is gone and the history says **Expired**: make it again.

Officers with an export permission see every file the association has made. Someone with only the **view export history** permission sees just the files they made themselves.
