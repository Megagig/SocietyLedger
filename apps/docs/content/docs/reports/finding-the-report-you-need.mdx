Five reports, each answering a different question. Use this table to find the right one.

## How it works

| Question | Report |
|---|---|
| How much came in, and how does it compare to last period? | [Financial summary](/docs/reports/financial-summary) |
| What does each member still owe? | [Member balances](/docs/reports/member-balances) |
| How long has money been outstanding? | [Aging analysis](/docs/reports/aging-analysis) |
| What percentage of what you charged gets paid? | [Collection rate](/docs/reports/collection-rate) |
| How does it break down by category? | [Income by category](/docs/reports/income-by-category) |

On the web, they are under **Reports**. In the app, go to **Manage**, then **Reports**: the first screen shows this month at a glance, with the same figures you can open, and lists each report and **Exports**.

Every figure in every report can be opened to the records behind it: see [Opening a figure](/docs/reports/drilling-into-a-figure).

## Why it matters

Each report reads the same charges and payments but groups them differently. Picking the right one the first time saves you cross-checking several, and the rules are the same in all of them, so they agree.

## What you can do

- [Exporting to PDF and Excel](/docs/reports/exporting-reports) — download any of these once you have found the right one.
