Five reports, each answering a different question — use this table to find the right one.

## How it works

| Question | Report |
|---|---|
| How much came in, and how does it compare to last period? | [Financial summary](/docs/reports/financial-summary) |
| What does each member still owe? | [Member balances](/docs/reports/member-balances) |
| How long has money been outstanding? | [Aging analysis](/docs/reports/aging-analysis) |
| What percentage of what's expected gets collected? | [Collection rate](/docs/reports/collection-rate) |
| How does income break down by category? | [Income by category](/docs/reports/income-by-category) |

## Why it matters

Each report pulls from the same underlying data but groups it differently — picking the right one the first time saves you cross-checking several.

- [Exporting to PDF and Excel](/docs/reports/exporting-reports) — download any of these once you've found the right one.
