Donations have two layers: a general donation **category**, and optional specific **allocations** — causes members can direct their giving toward.

## Before you start

You need the **create categories** permission, which Administrators and Treasurers have by default.

## Set up a donation category

<Steps>
<Step>Go to <MenuPath items={["Finance", "Donations"]} />.</Step>
<Step>Select **Create Category**, give it a **Name**, and save.</Step>
</Steps>

<Screenshot src="/images/finance/donations-and-causes-1.webp" alt="Donations page's Allocations tab, showing an empty state with a Create Allocation button" />

## Create a cause (allocation)

<Steps>
<Step>Switch to the **Allocations** tab and select **Create Allocation**.</Step>
<Step>Give it a **Name**, **Description** and, if relevant, a **Target Amount**.</Step>
<Step>Save.</Step>
</Steps>

## What happens next

Members can now give toward the category generally, or a specific allocation if you've created one — each donation appears under **Recent Donations** with its receipt number, and in the donor's own [donation history](/docs/member-guide/making-a-donation).
