Three separate fields describe a member: their category, their membership status, and whether they can log in.

## Category

| Category | Meaning |
|---|---|
| Regular | The default category for an ordinary member. |
| Executive | A member of the executive committee. |
| Honorary | An honorary member. |
| Student | A student member. |

## Status

| Status | Meaning |
|---|---|
| Active | Can log in and participate fully. |
| Inactive | Login disabled; record kept. Set this for a member who's stopped participating. |
| Suspended | Login disabled; record kept. Set this for a temporary restriction. |
| Terminated | Set automatically when a member is deleted — their record is kept but they're permanently removed from the active list. |

## Login status

| Login status | Meaning |
|---|---|
| Not Invited | No invitation has been sent yet, or the member has no email on file. |
| Invited | An invitation was sent but the member hasn't finished signing up. |
| Active | The member has a working login. |
