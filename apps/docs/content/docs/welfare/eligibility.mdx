Eligibility isn't a separate screen — it's checked live, right where a member requests support, against the rules you set when [creating the fund](/docs/welfare/welfare-funds).

## How it works

A member is eligible for a fund when all three are true:

1. **Waiting period** — they've belonged to the association for at least the fund's **Waiting Period (Days)**.
2. **Minimum contributions** — they've contributed in at least the fund's **Min. Contribution Months** (unique calendar months, not a running total).
3. **No open request** — they don't already have a pending or approved request on the same fund.

When a member selects a fund on the Request Support form, a green **"You are eligible for this fund"** or red **"✗ [reason]"** message appears immediately, and **Submit Request** stays disabled until they are.

## Why it matters

A fund with **Waiting Period** and **Min. Contribution Months** both set to 0 (the default) has no real restriction — anyone can request from it immediately. Set these deliberately for funds where you want members to contribute first.
