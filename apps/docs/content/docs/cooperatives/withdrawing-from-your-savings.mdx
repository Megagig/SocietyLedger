You ask for a withdrawal in the app; officers decide it. Your balance only changes when the request is finally approved, and you can cancel it until then.

## Before you start

Only savings types that allow withdrawals can be withdrawn from. Share capital never can. Your cooperative may also set a **monthly limit** for a type, and savings held against a loan can't leave until the loan is repaid.

## Request a withdrawal

<Steps>
<Step>Open <MenuPath items={["Savings", "My Withdrawal"]} /> (on the phone: **Money → My Withdrawal**).</Step>
<Step>Select **New withdrawal request**.</Step>
<Step>Choose the savings to **Withdraw from**. You'll see its balance and, if there is a limit, how much you can still withdraw this month.</Step>
<Step>Enter the **Amount** and, if you like, a **Reason**, then select **Request withdrawal**.</Step>
</Steps>

## What happens next

By default a request goes through two stages: one officer **reviews** it (checks you are eligible and the balance is there), and a different officer **approves and pays** it. Each stage is shown on your request in words, for example *Reviewed. Waiting for a second officer to approve and pay.* If a cooperative has too few officers it may run a single stage instead.

You are told when it is decided. If it is not approved, the reason is shown. The balance, any savings held for a loan, and the monthly limit are checked again at the final approval, so a request can still be turned down if something changed meanwhile. You can have only one request waiting for each savings type at a time.
