A template is a message you use again and again, such as a dues reminder. Put a word in braces, like `{name}`, where a member's own detail should go.

## Before you start

You need the **manage SMS templates** permission to add, change or delete templates. Anyone who can view SMS can read them.

## Add or change a template

<PlatformTabs>
<PlatformTab>
<Steps>
<Step>Go to <MenuPath items={["Communication", "SMS Templates"]} /> and select **New Template**.</Step>
<Step>Enter a **Name**, choose a **Category** and write the message (up to 918 characters).</Step>
<Step>Select **Create**. To change one, open it from the list.</Step>
</Steps>
</PlatformTab>
<PlatformTab>
<Steps>
<Step>Go to <MenuPath items={["Manage", "Communication", "Message templates"]} /> and tap **+**.</Step>
<Step>Enter a **Name**, choose the **Kind** and write the message.</Step>
<Step>Tap **Add template**. Tap a template in the list to change or delete it.</Step>
</Steps>
</PlatformTab>
</PlatformTabs>

Use a template when writing a campaign: pick it and its wording fills the message box, where you can still change it. A campaign keeps its own copy, so deleting a template never changes campaigns that used it.
