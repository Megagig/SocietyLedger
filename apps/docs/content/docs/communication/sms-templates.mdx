Templates let you write a reusable message with placeholders — `{{name}}`, `{{amount}}` — once, and reuse it in Quick Send or a campaign.

## How it works

<MenuPath items={["Communication", "SMS Templates"]} /> lists templates by category and lets you filter them. This part works and loads correctly.

<Screenshot src="/images/communication/sms-templates-1.webp" alt="SMS Templates page, currently empty, with a category filter and New Template button" />

<Callout type="danger" title="Creating a template currently fails">
Filling in **New Template** and saving fails with a validation error every time — the form sends the message under the field name `message`, but the API expects `content`. Confirmed directly against the API; it's logged for a fix in a later phase.
</Callout>

## Why it matters

Until this is fixed, write out each SMS message by hand rather than relying on a saved template.
