Some people belong to more than one association — maybe an alumni association and a cooperative, for example. Each one is entirely separate.

## How it works

There's no single combined account that covers every association you belong to. Instead, you have a **separate account for each one** — even if you use the same email address for both. Signing in happens at each association's own web address, with whichever password you set there.

There's no in-app "switch association" control today — to move between them, you sign in at each one's own address, the same way you would for any other sign-in.

## Why it matters

Because each account is separate, something that happens in one association — a suspended account, a changed password, a different role — has no effect on any other association you belong to. If you can't remember which address or password goes with which association, that's the first thing to check.
