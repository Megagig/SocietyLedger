Once a poll is created, you start it, members answer, and you close it. Whoever runs polls can read the answers at any time.

## Run the poll

<PlatformTabs>
<PlatformTab>
<Steps>
<Step>Open the poll from <MenuPath items={["Governance", "Polls"]} /> and select **Start Poll**.</Step>
<Step>Members answer from the poll's own page.</Step>
<Step>When the response window should end, select **Close Poll**. The results then show every option's count and percentage.</Step>
</Steps>

<Screenshot src="/images/elections/poll-results-1.webp" alt="Closed poll showing Results with Yes at 100% (1 vote) and No at 0%" />
</PlatformTab>
<PlatformTab>
<Steps>
<Step>Open the poll from <MenuPath items={["Manage", "Voting", "Polls"]} /> and tap **Start poll**.</Step>
<Step>Members answer from <MenuPath items={["Community", "Polls"]} />. The poll's page shows how many have answered and each answer's share.</Step>
<Step>Tap **Close poll** when the window should end.</Step>
</Steps>
</PlatformTab>
</PlatformTabs>

A poll can be started once and closed once. A draft or open poll can be **cancelled**, and a draft or cancelled poll nobody answered can be deleted — one with answers is kept as a record.

## Who sees the answers

While a poll is open, members don't see the running answers unless the poll was set to show results while it is open; they see them when it closes. The people who run polls always see them. A member answers once, and can't change the answer.
