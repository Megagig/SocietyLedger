Every election moves through the same stages, in order. You trigger each move yourself — nothing advances automatically except quorum and turnout numbers.

| Stage | What you do | What members see |
|---|---|---|
| Draft | Create the election and its positions. | Nothing yet. |
| Nominations Open | Members and officers put candidates forward. | The election, open for nominations. |
| *(back to Draft)* | Close nominations once you have your candidates. | Nothing changes for members. |
| Voting Open | Start voting. | The ballot, ready to vote. |
| Voting Closed | Close voting once the window ends. | The election shows as closed; no results yet. |
| Results Published | Publish the results. | — see [Publishing results](/docs/elections/publishing-results) for what's actually visible today. |

<Callout type="warning" title="Closing nominations returns the election to Draft">
Selecting **Close Nominations** moves the election back to the same **Draft** badge it started with — this is correct, not a mistake, but it looks like nominations never happened. Your candidates are still there; see [Running the vote](/docs/elections/running-the-vote) for how to get from here to a live ballot.
</Callout>

An election can be cancelled from any stage before results are published.

## Why it matters

Each stage is a deliberate, one-way gate — once nominations close, no more candidates can be added for that election; once voting closes, no more votes count. Plan your dates before you open nominations, since there's no way to extend a window after the fact except by cancelling and starting over.
