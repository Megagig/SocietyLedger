SocietyLedger gives every member an in-app notification inbox, lets officers broadcast announcements, and includes a full SMS module for one-off messages and bulk campaigns.

<Callout type="warning" title="The SMS section has real, confirmed problems right now">
The SMS dashboard, templates list and message history all load correctly. But **every action that sends something — Quick Send, creating a campaign, creating a template — currently fails** with a validation error the moment you submit it, because the page you reach from the sidebar sends a different data shape than the API expects. This isn't a one-off: it affects every SMS write action in the reachable UI. See the individual pages below for what's actually usable today, and [Sending an SMS](/docs/communication/sending-sms) for the full picture.
</Callout>
