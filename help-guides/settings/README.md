# Settings - Managing Your Association

## What this module is for

The Settings module lets you configure how your association operates. You can update your association's profile, control how members join, set up payment methods, manage notifications, and configure various other options that affect how the system works for your organization.

## Who can use it

**Full Access:**
- Association Administrators
- Super Administrators

**Limited Access:**
- Treasurers (can view and edit payment-related settings only)
- Financial Secretaries (can view most settings but cannot edit)

**No Access:**
- Regular Members

## What you can do in this module

### Association Profile
- Update your association's name and type
- Add or change contact information
- Upload and manage your association logo
- Set your timezone and currency

### Member Access Control
- Allow or prevent new members from signing up themselves
- Set what role new members get by default
- Require approval for new member registrations
- Set how long invitation links stay valid

### Financial Settings
- Configure late fee policies for overdue payments
- Set grace periods for payments
- Choose your currency and how amounts are displayed
- Enable or disable partial payments

### Payment Methods
- Turn payment channels on or off (bank transfer, cash, online payments)
- Set which payment method is used by default
- Configure automatic receipt generation
- Set up payment approval requirements

### Notifications
- Choose when to send payment reminders (how many days before due dates)
- Enable or disable email and text message notifications
- Set quiet hours when notifications won't be sent
- Configure who notifications come from

### External Services
- Connect payment gateways like Paystack for online payments
- Set up text message providers for notifications
- Enable advanced features (may require higher subscription plans)

### Data & Privacy
- Set how long to keep old records
- Configure data export options
- Manage privacy compliance settings
- Control what happens to inactive member data

### Activity History
- View a log of all changes made to settings
- See who made changes and when
- Track what was changed from old values to new values
- Export activity records for your records

## Common use cases

### Setting up a new association
1. Go to Association Profile and fill in your organization's details
2. Upload your logo to make the system feel more personalized
3. Set your timezone and currency to match your location
4. Configure member access rules based on how you want people to join
5. Set up your preferred payment methods
6. Configure notification preferences

### Preparing for payment collection
1. Go to Financial Settings and set your late fee policy
2. Choose how many days grace period members get
3. Set up Payment Methods with your preferred options
4. Configure notification reminders (typically 7 days, 3 days, and 1 day before due)
5. Test that receipts generate correctly

### Managing member registration
1. In Member Access settings, decide if people can sign up themselves
2. Set the default role for new members (usually "Member")
3. Choose whether new registrations need approval
4. Set invitation link expiry (typically 72 hours)

### Connecting online payments
1. Go to External Services settings
2. Enable your preferred payment gateway (like Paystack)
3. Enter your account keys from the payment provider
4. Test with a small transaction to ensure it works
5. Update Payment Methods to include the new online option

## Important notes and limitations

### Financial Settings Changes
⚠️ **Important:** Changes to financial settings (like late fees or grace periods) only affect NEW transactions. Existing payments and dues are not changed retroactively.

### Logo Requirements
- Maximum file size: 2MB
- Supported formats: JPEG, PNG, WebP
- Recommended size: Square images work best (like 200x200 pixels)

### Permission Restrictions
- Only administrators can change most settings
- Treasurers can only modify payment and billing-related settings
- Some advanced features require higher subscription plans

### Data Privacy
- Changes to data retention policies only affect future data
- Existing records follow the retention rules that were in place when they were created
- Some privacy features may be required by law in your jurisdiction

### Backup Your Settings
- Use the "Export All Settings" feature regularly to backup your configuration
- Keep exported files safe as they contain sensitive configuration information
- Settings exports can help when setting up similar associations

### Getting Help
If you're unsure about a setting, hover over the help icons (ℹ️) next to options for more details. When in doubt, contact your system administrator before making changes that affect the whole association.
