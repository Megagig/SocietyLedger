# Elections & Voting - Running Democratic Processes

## What this module is for

The Elections & Voting module helps your association run fair and transparent elections for leadership positions and conduct polls to gather member opinions. You can set up elections with multiple positions, manage candidate nominations, conduct secure voting, and automatically count results.

## Who can use it

**Full Management (Create, Edit, Manage Elections):**
- Association Administrators

**Nominate and Vote:**
- All Active Members (can nominate themselves or others and cast votes)

**View Results:**
- All Members (can see published election results and poll outcomes)

## What you can do in this module

### Election Management
- Create elections for leadership positions (President, Secretary, Treasurer, etc.)
- Set nomination periods when candidates can register
- Schedule voting periods with start and end times
- Publish results when voting is complete

### Candidate Management
- Allow members to nominate themselves for positions
- Enable administrators to nominate members
- Approve or reject candidate applications
- Let candidates withdraw from elections

### Voting Process
- Cast votes for candidates in each position
- Choose to abstain from voting on specific positions
- Ensure each member can only vote once per position
- Maintain voting privacy (anonymous voting option)

### Polls and Surveys
- Create quick polls for member feedback
- Set up yes/no questions or multiple choice options
- Gather opinions on association policies or decisions
- View real-time results as responses come in

### Results and Analytics
- Automatically count votes when elections close
- Display winner announcements
- Show voting statistics and participation rates
- Export results for record-keeping

## Common use cases

### Setting up an annual election
1. Create a new election titled "2025 Executive Committee Election"
2. Add positions like President, Vice President, Secretary, Treasurer
3. Set nomination period (e.g., 2 weeks for members to register as candidates)
4. Set voting period (e.g., 3 days for all members to cast votes)
5. Choose whether voting should be anonymous
6. Publish the election to notify all members

### Managing candidate nominations
1. Open nominations for the election
2. Review self-nominations as they come in
3. Approve candidates who meet eligibility requirements
4. Contact candidates if additional information is needed
5. Close nominations when the period ends
6. Publish the final candidate list

### Conducting the voting process
1. Start voting when the nomination period ends
2. Send reminders to members who haven't voted yet
3. Monitor voting participation throughout the period
4. Answer member questions about the voting process
5. Close voting at the scheduled end time

### Creating a quick poll
1. Click "Create New Poll"
2. Enter your question (e.g., "Should we increase the meeting frequency?")
3. Add answer options (Yes/No or multiple choices)
4. Set how long the poll should run
5. Publish to all members and watch responses come in

### Handling election results
1. Review the vote counts when voting closes
2. Verify results are accurate
3. Publish results to announce winners
4. Send congratulations to elected candidates
5. Archive the election for future reference

## Important notes and limitations

### Election Types
- **General Election:** Regular elections for multiple positions
- **By-Election:** Special election to fill a vacant position
- **Referendum:** Vote on specific policies or constitutional changes

### Election Workflow
Elections follow a strict sequence:
1. **Draft:** Election is being set up
2. **Nominations Open:** Candidates can register
3. **Nominations Closed:** Candidate list is final
4. **Voting Open:** Members can cast votes
5. **Voting Closed:** No more votes accepted
6. **Results Published:** Winners announced

### Voting Rules
- Each member can vote only once per position
- Members cannot change their vote after submitting
- Anonymous voting means votes cannot be traced back to voters
- Members can choose to abstain (not vote) for any position

### Candidate Requirements
- Candidates must be active members of the association
- Some positions may have additional eligibility requirements
- Candidates can withdraw at any time before voting starts
- Self-nomination may require administrator approval

### Poll Types
- **Yes/No:** Simple binary choice questions
- **Single Choice:** Pick one option from multiple choices
- **Multiple Choice:** Select several options from a list
- **Ranked Choice:** Order preferences from most to least preferred

### Voting Security
⚠️ **Important:** The system ensures election integrity by preventing duplicate voting and maintaining voter privacy when anonymous voting is enabled.

### Quorum and Validity
- Elections may require a minimum number of voters to be valid
- Check your association's rules for quorum requirements
- Low turnout elections may need to be repeated
- Document participation rates for transparency

### Results Publication
- Results are automatically calculated when voting closes
- Winners are determined by simple majority (most votes wins)
- Tied elections may require a runoff vote
- All results should be announced to the membership

### Technical Considerations
- Members need valid email addresses to receive voting notifications
- Voting links are unique and cannot be shared between members
- The system prevents voting outside the scheduled time periods
- All voting activity is logged for audit purposes

### Getting Help
- If you can't vote, check that the voting period is currently open
- Contact administrators if you're having trouble with candidate registration
- For questions about election rules, refer to your association's constitution
- Technical voting issues should be reported immediately to ensure fair elections
