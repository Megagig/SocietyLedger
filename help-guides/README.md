# User Help Guides

This directory contains user-friendly help documentation for the SocietyLedger application. These guides are written for non-technical end users and explain how to use each module of the system.

## Available Modules

### Core Management
- [Members](./members/README.md) - Managing member profiles, registration, and access
- [Finance](./finance/README.md) - Financial categories, transactions, and reporting
- [Settings](./settings/README.md) - Configuring your association settings

### Governance & Operations
- [Meetings](./meetings/README.md) - Scheduling meetings, tracking attendance, and recording minutes
- [Elections](./elections/README.md) - Running elections and polls for your association
- [Communications](./communications/README.md) - Sending messages and notifications to members

### Financial Services
- [Payments](./payments/README.md) - Processing payments and managing billing
- [Cooperatives](./cooperatives/README.md) - Savings accounts and loan management
- [Reports](./reports/README.md) - Generating financial and member reports

### Administration
- [Roles & Permissions](./roles/README.md) - Managing user access and permissions
- [Data & Privacy](./data-privacy/README.md) - Data management and privacy settings
- [Platform Admin](./platform-admin/README.md) - System-wide administration (Super Admin only)

## How to Use These Guides

Each module guide follows a consistent structure:

1. **What this module is for** - Brief overview of the module's purpose
2. **Who can use it** - Which roles or permission levels can access features
3. **What you can do** - List of available features and actions
4. **Common use cases** - Real-world examples of how to use the module
5. **Important notes** - Warnings, limitations, or special considerations

## Getting Help

If you need additional assistance beyond these guides, contact your association administrator or system support.
