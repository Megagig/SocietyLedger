## Tracking & Monitoring

### Metrics to Track
- **Total Backlinks:** Count of all links
- **Referring Domains:** Unique domains linking
- **Domain Authority:** Quality of linking sites
- **Anchor Text:** Text used in links
- **Link Type:** Dofollow vs nofollow
- **Link Location:** Homepage, blog post, footer

### Tools
- **Google Search Console** (free)
  - See all backlinks
  - Monitor new links

- **Ahrefs** (paid)
  - Comprehensive backlink data
  - Competitor analysis

- **SEMrush** (paid)
  - Backlink audit
  - Link building tools

### Monthly Report
Track progress:
- New links acquired
- Lost links
- Domain authority changes
- Referring domains growth
